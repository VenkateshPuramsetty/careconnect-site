# CareConnect India 🌍

**CareConnect India** is a community-driven platform designed to bridge the gap between elderly citizens in need of support and medical students eager to help.

This site provides a simple, accessible interface for:

- Elderly users to register and request support
- Medical students to volunteer their time and care
- Family members to stay informed and reassured

Live Site: [https://venkateshpuramsetty.github.io/careconnect-site/](https://venkateshpuramsetty.github.io/careconnect-site/)

---

## 🔧 Features

- 📄 Informational Homepage
- 🧓 Elderly Registration Form
- 👨‍⚕️ Student Registration Form
- 🔐 Login with Dashboard Redirection
- 🧭 Student and Elderly Dashboards
- 🧑‍💻 Fully Responsive Design
- 🌐 Hosted on GitHub Pages

---

## 🧪 How to Use

1. Visit the [Homepage](https://venkateshpuramsetty.github.io/careconnect-site/)
2. Register as an elderly user or volunteer
3. Login to access your personalized dashboard
4. Explore site navigation to understand the workflow
